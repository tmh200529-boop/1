# 原神自动操作脚本

Windows 下运行:

```
pip install -r requirements.txt
python genshin_auto.py     # 需管理员权限的终端
```

| 热键 | 功能 |
| --- | --- |
| F6 | 自动剧情(空格推进 / F 选择选项) |
| F7 | 自动拾取(连按 F) |
| F8 | 自动战斗循环(E → Q → 普攻,可在 `config.json` 修改) |
| F9 | 退出 |

- 仅当前台窗口标题含“原神”时才发送按键(`window_title` 可改)。
- 按键绑定默认为游戏默认键位,改过键位请同步修改脚本。
- ⚠ 米哈游用户协议禁止第三方自动化,有封号风险,请自行承担。
